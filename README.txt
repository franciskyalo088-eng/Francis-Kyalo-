FRANCIS KYALO WEBSITE — 3 PAGES

Files:
- index.html  (Home)
- about.html  (About)
- vision.html (My Vision)
- style.css   (design)
- script.js   (small footer year helper)

PREVIEW ON ANDROID:
1. Extract this ZIP using your phone's Files app.
2. Open the extracted folder.
3. Tap index.html and choose Chrome.
4. Use the navigation at the top to visit all three pages.

PUBLISH ONLINE WITH GITHUB PAGES:
1. Sign in to the GitHub account where you want this site.
2. Create a NEW public repository named: francis-kyalo
3. Upload all five website files (index.html, about.html, vision.html, style.css, script.js) to the repository root. Do not upload the ZIP alone.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait a few minutes and open:
   https://YOUR-GITHUB-USERNAME.github.io/francis-kyalo/

Replace YOUR-GITHUB-USERNAME with the exact GitHub username. The site is mobile-friendly and works in Chrome.
